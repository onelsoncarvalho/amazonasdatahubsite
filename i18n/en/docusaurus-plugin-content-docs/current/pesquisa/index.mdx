# Search

With the high demand for professionals in statistics and data science,
the creation of support materials, which favor a process of
learning becomes necessary. In this scenario, AmazonasDataHub, with the
provision of treated databases, reproduction of results
scientific research and analysis of regional data favors the contribution to
didactic purposes, both in teaching and knowledge.

## Installation

If you have not installed `amazonasdatahub`, see the documentation for
me Python and R versions:
