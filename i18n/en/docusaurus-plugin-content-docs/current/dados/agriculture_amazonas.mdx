# agriculture_amazonas

Plant production data from the Institute for Agricultural and Livestock Development
Amazonas Sustainable Forestry (2023)

### Description

This database, which is the consolidation of data from the
IDAM activities, brings data on plant production of crops in which
this institute considers to be priorities.

### Usage


```r
agriculture_amazonas
```

### Format

‘agriculture_amazonas’ A data frame with 1072 lines and 13 columns:

#### municipality

Municipality

#### local_unit

IDAM Local Unit

#### n_beneficiary

Number of beneficiaries assisted

#### planted

Planted area in hectares (ha)

####harvested

Harvested area in hectares (ha)

#### production

Production (in the unit of measure - measure)

#### estimated_n_beneficiary

Estimate for the number of beneficiaries

#### estimated_planted

Estimate for planted area (ha)

#### estimated_harvested

Estimate for harvested area (ha)

#### estimated_production

Estimate for production (in the unit of measurement - measure)

#### measure

Production measurement unit

#### cultivation

Cultivation

#### year

Year of cultivation
