# humidity_manaus

Time series with limited range extreme values

### Description

A time series database consisting of minimum moisture
relative observed in the city of Manaus, from January 2009 to December
2020. This database is a sample with size n = 144 blocks
monthly.

### Usage


```r
humidity_manaus
```

### Format

‘humidity_manaus’ A tibble with 144 lines and 5 columns.

#### year

Year in which the observation was made.

#### HR

Relative Humidity

#### dbt

Dry Bulb Temperature

#### wbt

Wet Bulb Temperature

#### month

Month in which the observation was made.

### Source
