# aids_amazonas

A database of AIDS occurrences from 2011 to 2023 in Amazonas.

### Description

This database has records of AIDS occurrences from 2011 to
2023 in each municipality of Amazonas.

### Usage


```r
aids_amazonas
```

### Format

‘aids_amazonas’ A data frame with 1612 lines and 5 columns:

#### code_muni

Municipal code

#### name_muni

Name of the municipality

#### cases

Case count

#### gender

Individual's gender (M for Male and F for Female)

#### year

Year of observation

### Source

https://indicadores.aids.gov.br/
