# Pesquisa

Com a alta demanda por profissionais em estatística e ciência de dados,
a criação de materiais de apoio, que favoreçam um processo de
aprendizado torna-se necessária. Nesse cenário, o AmazonasDataHub, com a
disponibilização de bases de dados tratadas, a reprodução de resultados
científicos e análise de dados regionais favorece a contribução para
fins didáticos, tanto em ensino quanto em conhecimento.

## Instalação

Caso não tenha instalado o `amazonasdatahub`, veja a documentação das

## Histórico

- 2024: Começo da Iniciação Científica: “AmazonasDataHub: uma biblioteca
  de dados em R”
- 2025: XII SECT ICE - Melhor trabalho na área de Estatística, na
  modalidade de Pôster: AmazonasDataHub: Uma Biblioteca de Dados em R,
  Universidade Federal do Amazonas.
- 2026: Trabalho de Conclusão de Concurso - “AmazonasDataHub: Integrando
  Dados, Pesquisa e Ensino”
